## Changes in 1.29.1

- Adjusted the About dialog layout so that the mpv link appears directly below the acknowledgement.
- Shortened the codec note to identify **libmpv-2.dll** as optional.

## Download

- **JustPlayVideo-1.29.1-Setup.exe** — Windows 11 x64 installer.
- **version.txt** — version number for a future update-checking feature.
- **SHA256SUMS.txt** — SHA-256 checksum of the installer.

The optional mpv engine is not included. Without it, playback uses the native Windows engine and available Windows codecs. You can download mpv during installation or later from **Options > Playback engine > Download the mpv engine...**.
